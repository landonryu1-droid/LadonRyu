# LadonRyu Live Translator

## Overview
LadonRyu Live Translator is a real-time translation and text-to-speech streaming application.

### Project Structure
This project contains both backend services for translation and TTS, as well as a frontend for user interaction.

## Backend Services
- `translation_service`: Handles translation tasks.
- `tts_service`: Manages text-to-speech functionalities.
- `streaming_service`: Streams translations and audio to clients.

## Frontend
The frontend consists of components for user interaction and displays the results of translations.
